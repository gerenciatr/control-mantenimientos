ACTUALIZAR EN GITHUB
Descomprime y reemplaza index.html, app.js y style.css en la raíz del repositorio. Conserva logo-transintercol.png. Pulsa Commit changes y recarga con Ctrl + F5 cuando termine la publicación. Descarga un respaldo antes de actualizar. Los datos se conservan usando el mismo navegador y dirección.

CONSOLIDADO GENERAL
Pulsa Consolidado general arriba de la página. Muestra todos los vehículos, odómetro, fecha de última lectura diaria, kilómetros faltantes por servicio y estado general. Usa Descargar imagen PNG para enviar la tabla completa al director de operaciones. La imagen refleja los datos actuales de tu navegador: confirma y actualiza los odómetros antes de enviarla. Si no hay lecturas diarias dice Excel / inicial, sin inventar una fecha.

ESTADOS
Excedido (rojo): algún servicio tiene kilómetros faltantes negativos.
Pendientes (gris): falta configurar algún servicio y no hay ninguno excedido.
Próximo (naranja): todos configurados, ninguno excedido y alguno tiene entre 0 y 700 km faltantes.
Normal (verde): todos configurados y todos tienen más de 700 km faltantes.
El estado excedido tiene prioridad sobre datos pendientes. Cada celda del consolidado muestra su propio estado. Los datos desconocidos dicen Sin configurar.

ELIMINAR VEHÍCULOS
Selecciona una placa y pulsa Eliminar vehículo junto a Configurar últimos mantenimientos. Confirma para eliminar la placa y su historial. Puedes eliminar incluso el último vehículo y luego agregar uno nuevo. Restaura un respaldo para recuperar datos eliminados.
